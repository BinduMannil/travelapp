# Journee Design Lock

Journee has a permanent design governance lock.

The master specification is here:

`docs/JOURNEE_MASTER_LOCK_SPEC.md`

That file is mandatory for all future agents and contributors. It defines the locked cinematic identity, homepage behavior, typography, transitions, atmosphere behavior, navigation treatment, profile behavior, image rotation rules, and anti-dashboard guardrails.

## What Is Locked

- Homepage behavior is locked, including the cinematic hero, hidden image rotation, 60000 ms rotation interval, slow cross-fades, atmosphere layers, and the ban on visible slideshow UI.
- Cinematic styling is locked, including full-bleed imagery, dark atmospheric layering, warm gold accents, glass, vignette, haze, grain, and restrained premium motion.
- Typography is locked, including the display hierarchy, editorial heading tone, uppercase micro-labels, and quiet sans controls.
- Transitions are locked as slow, cinematic, and subtle rather than fast, flashy, or dashboard-like.
- Profile behavior is locked as a cinematic traveler profile and "My Journee" experience, not a generic account portal.

## Agent Requirement

Before changing Journee UI, read `docs/JOURNEE_MASTER_LOCK_SPEC.md` and follow it. Never override the master specification unless the user explicitly requests modification of the master specification itself.
